1. Ringkasan Eksekutif & Kronologi Insiden

Mahasiswa KKN di lapangan mendapati kendala kritis: mahasiswa yang telah bertugas selama 240 s.d. 300 menit (4 - 5 jam) mendadak melihat timer di layar aplikasi Flutter Mobile berbalik menjadi 0 Menit.

Tim Backend telah menyelesaikan perbaikan SSOT (Single Source of Truth) di sisi API:

  • Refactoring Algoritma Jeda (calcTotalPauseMs): Menghapus naif interval looping, menerapkan Interval Merging sehingga jeda overlapping tidak dihitung ganda dan $0 \le \text{pauseMs} \le \text{grossMs}$.
  • Pembersihan Catch Block Fallback (kknAttendanceController.ts): Menghapus respon palsu HTTP 200 { actualInZoneMinutes: 0 } dan mengembalikan HTTP 500 semantik.
  • Standardisasi Jam Masuk: Respon ping kini konsisten menyertakan attendedAt dan jam_masuk.

2. Bedah 3 Celah Kritis di Sisi Aplikasi Mobile

Investigasi forensik kode Flutter Mobile menemukan penyebab mengapa mobile menelan angka 0:

  1. Flaw Operator Fallback (int.tryParse('0')): Nilai int.tryParse('0') menghasilkan integer 0 (BUKAN null). Akibatnya, operator ?? _backendDurationMinutes tidak pernah aktif. Nilai lokal 300 menit langsung ditimpa menjadi 0.
  2. Ketiadaan Start-Time Fallback: Jika server mengembalikan 0 atau payload ping tidak membawa waktu mulai, klien tidak memanfaatkan state.attendanceTime untuk menghitung durasi berjalan.
  3. Ketiadaan Monotonic Protection: Durasi sesi aktif tidak memiliki perlindungan dari regresi/drop drastis ke 0 di tengah sesi berlangsung.

A. File: kkn_location_controller.dart (Tambahkan Helper Proteksi)

  int _resolveSafeDurationMinutes({
    dynamic minutesVal,
    dynamic secondsVal,
    String? attendedAtStr,
    int currentDuration = 0,
    bool isSessionActive = false,
  }) {
    int? parsedMins;
    if (minutesVal != null) {
      parsedMins = int.tryParse(minutesVal.toString());
    } else if (secondsVal != null) {
      final secs = num.tryParse(secondsVal.toString());
      if (secs != null) parsedMins = (secs / 60).ceil();
    }

    final effectiveStartStr = attendedAtStr ?? state.attendanceTime;
    int? elapsedFromStart;
    if (effectiveStartStr != null) {
      final startTime = DateTime.tryParse(effectiveStartStr)?.toLocal();
      if (startTime != null) {
        final diff = DateTime.now().difference(startTime).inMinutes;
        if (diff >= 0) elapsedFromStart = diff;
      }
    }

    if (parsedMins != null && parsedMins > 0) {
      if (isSessionActive && currentDuration > 0 && parsedMins < (currentDuration - 30)) {
        return currentDuration; // Tolak anomali drop drastis
      }
      return parsedMins;
    }

    // PROTEKSI ANTI-RESET-0:
    if (isSessionActive && (currentDuration > 0 || (elapsedFromStart != null && elapsedFromStart > 1))) {
      return currentDuration > 0 ? currentDuration : (elapsedFromStart ?? 0);
    }
    return parsedMins ?? currentDuration;
  }
